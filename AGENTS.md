# Code Style General Notes

Please try to copy the existing code style if possible.
This includes how variables and functions are organized.
Be mindful of other files, and keep ordering and conventions similar across different files.
Put variables before methods in the definition of types, interfaces, classes, and stores.

# Dependencies

Please do not use extremely outdated or suspicious dependencies.
Do not be afraid to write something you need on your own if it is a very small amount of code and easy to write correctly.

# JavaScript/TypeScript Code Style

Leave a line with just a closing bracket instead of putting else or else if on the same line as the bracket.
Do the same with catch and finally in try catch blocks.
